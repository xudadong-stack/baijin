## 角色成长与吃喝

**开局试算。** 建角时选择性别并分配四维，界面实时显示剩余点数和属性作用。合法分配用完配置点数，且每项落在允许范围内。确认后在小镇起点创建角色。开放后天修炼和装备后，界面可查看基础属性及各项增益。

| 属性 | 开局作用 | 成长后的用途 |
| --- | --- | --- |
| 膂力 | 增加普通攻击的基础伤害 | 参与部分兵器的使用条件 |
| 敏捷 | 提高命中和闪避 | 参与逃跑判定，轻功可以提供额外修正 |
| 悟性 | 降低请教的潜能消耗，最低消耗为 1 | 参与各项基本功和门派武学的请教费用折减。[请教与练功](martial-arts.md#请教与练功) |
| 根骨 | 提高气血上限 | 影响内力上限及修炼恢复 |

| 试玩参数 | 试算值 |
| --- | --- |
| 四维 | 每项从 4 起，可另分配 12 点，每项上限 10 |
| 气血上限 | 30 + 3 × 根骨，建角时气血全满 |
| 基础内力上限 | 8 + 2 × 根骨，建角时内力全满 |
| 饥饿度 | 从 0 起，每 4 个游戏时间单位增加 1，上限 12 |
| 口渴度 | 从 0 起，每 3 个游戏时间单位增加 1，上限 10 |
| 吃喝 | 食用一份口粮降低饥饿度 6。到井边喝水降低口渴度 10，两项最低为 0 |
| 气血自然恢复 | 每 2 个游戏时间单位恢复 2 点，前提是结算增长后两项仍低于各自上限 |
| 内力自然恢复 | 每 3 个游戏时间单位恢复 2 点，前提是结算增长后两项仍低于各自上限 |
| 初始铜钱与口粮售价 | 建角得 12 枚铜钱，一份口粮售价 4 枚 |

开局每次成功移动推进一个游戏时间单位，按移动后的时间先增加饥饿度、口渴度，再判定气血和内力的自然恢复。恢复分别受有效气血上限与当前内力上限限制。角色可到老婆婆家院门旁买口粮，在背包里食用。喝水的动作由水井提供，规则内核在结算前校验角色已到井边。游戏时间和两项数值随进度保存。[老婆婆](npcs/town-street.md#老婆婆) · [内力规则](combat.md#气血内力受伤与疗伤)

探索时可随处从角色菜单选择打坐。打坐消耗的游戏时间、饥饿度、口渴度和恢复所得一同保存。[打坐数值](combat.md#气血内力受伤与疗伤)

**年龄规则草案。** 以累计游戏时间推进年龄，记录角色已经达到的人生阶段。阶段变化可触发一次属性成长或对话变化。年龄起点、阶段长度与对应增益在确定人物内容时配置。

**验收场景。** 令饥饿度在本次恢复时点恰好达到上限，核对该次自然恢复量为零。在井边喝水并食用口粮后推进到恢复时点，核对气血恢复且不超过上限。冷启动恢复同一游戏时间及状态。

### 幸运

幸运是建角时一次生成的隐藏属性。玩家确认合法的四维分配时，从 1 至 88 的整数中等概率抽取一个随机值。初始幸运为 `随机值 +（建角悟性 − 4）+（建角根骨 − 4）`，所有合法建角合计覆盖 1 至 100。

幸运用于建角相貌和战斗暴击，与初始角色状态一同保存。读档及后天属性成长继续使用已保存的幸运值。人物面板只展示四维、相貌等可见信息。[暴击率](combat.md#暴击)

### 相貌

建角确认合法配点后，先生成幸运，再用建角四维和这次生成的幸运计算相貌。合法四维总和固定为 28，按不同权重区分配点。根骨主要体现骨相，敏捷体现身姿，悟性体现神情，膂力体现体态。

```text
相貌分 = (膂力 − 4) + 3 × (敏捷 − 4) + 2 × (悟性 − 4) + 4 × (根骨 − 4) + floor(幸运 ÷ 2)
```

`floor` 表示向下取整。同样的建角四维和幸运得到同一档。男角、女角共用分档规则，性别决定在同一档使用哪句描述。

| 相貌档位 | 相貌分 | 男角描述 | 女角描述 |
| ---: | --- | --- | --- |
| 7 | 81 及以上 | 神采卓然，眉宇间自有风流。 | 姿容明艳，一颦一笑皆见风姿。 |
| 6 | 72 至 80 | 眉目俊逸，在人群中颇为惹眼。 | 眉目秀丽，举止娴雅。 |
| 5 | 63 至 71 | 眉眼俊朗，目光清亮。 | 眉目清秀，笑意明朗。 |
| 4 | 48 至 62 | 五官端正，举止利落。 | 五官匀称，仪态端方。 |
| 3 | 39 至 47 | 相貌寻常，眉目平和。 | 相貌寻常，眉目平和。 |
| 2 | 30 至 38 | 眉眼粗重，轮廓略显参差。 | 眉眼偏疏，轮廓略显生硬。 |
| 1 | 29 及以下 | 浓眉压眼，脸部轮廓颇为突兀。 | 阔额窄颌，五官相形悬殊。 |

四维均为 7 时，四维贡献为 30。幸运取 7、50、94 时，相貌分依次为 33、55、77，对应第 2、4、6 档。枚举 231 种合法配点和 88 个建角抽值，相貌分范围为 21 至 89，七档均可出现。以配点等权作比较，第 4 档占 34.09%，第 1、7 档各占 2.10%。

性别、幸运和相貌档位随初始角色状态一起保存。写入失败时重试同一份待保存状态。读档及后天四维、年龄或装备变化时，沿用建角时保存的档位。人物面板的相貌栏显示该档对应的描述。设有相貌要求的对白读取档位，例如最低 5 档时，第 5 至 7 档满足该条件。[交互与对白](npcs/dialogue.md#选择话题后的处理)

## 验收场景

### 开局

| 场景 | 检查步骤与通过条件 |
| --- | --- |
| 幸运生成 | 固定两组合法配点。悟性、根骨均为 4 时，随机值 1 对应幸运 1。两项均为 10 时，随机值 88 对应幸运 100。另用同一组配点输入两个不同的随机值，核对新建角色分别保存各自的幸运 |
| 相貌计算与分档 | 用四维均为 7 的角色分别注入抽值 1、44、88，核对相貌分为 33、55、77，分档为 2、4、6。固定幸运 50，按膂力、敏捷、悟性、根骨顺序输入 10／4／10／4 与 4／10／4／10，核对对应第 3、5 档。核对 29／30、38／39、47／48、62／63、71／72、80／81 两侧各落入相邻的档位 |
| 相貌文案与对白 | 用第 4 档的建角算例分别选男角、女角，核对相貌档位相同，面板分别显示各自对应的描述。用第 4、5 档角色检查最低要求为 5 档的话题，核对前者跳过该话题，后者显示该话题 |
| 隐藏幸运与续玩 | 确认建角后核对存档包含性别、幸运与相貌档位，人物面板只展示可见属性及相貌描述。模拟首次写入失败后重试，核对提交同一份建角结果。重启读档及提高后天悟性后，核对幸运、相貌档位和描述与建角结果一致 |
| 饥饿度与口渴度 | 建角后查看两项均为零。每次成功移动计一个游戏时间单位，推进到各自的配置间隔后核对两项增长及上限。在碰到障碍、停留菜单和进入后台后核对时间仍等于最近一次成功移动对应的值。重启后核对已保存的游戏时间和两项数值 |
| 购买与食用口粮 | 在老婆婆家院门旁查看售价和余额，新角色能用初始铜钱购买一份。核对扣除对应铜钱并增加一份口粮，余额不足时提示缺项。出现饥饿后食用口粮，核对口粮数量与饥饿度同步扣减，饥饿度最低为零。重启后核对余额、口粮数量和饥饿度 |
| 井边饮水 | 让角色口渴度大于零，核对饮水选项只在到达井边后出现。从离井位置直接提交饮水动作，规则内核返回位置不满足的反馈。到井边饮水后核对口渴度下降且最低为零。重启后核对已保存的口渴度 |
| 自然恢复条件 | 用气血低于上限的角色测试三种状态。两项均低于上限时按配置恢复气血，饥饿度或口渴度分别达到上限时该次自然恢复量为零。吃喝后两项降到上限以下，再推进到恢复时点，核对气血恢复 |
| 基础内力与自然恢复 | 根骨 4、7、10 的角色建角时分别具有满额内力 16、22、28。用根骨 7、当前内力 19 的角色步行至第 3、6 个时间单位，饥渴未满时依次到 21、22。另以饥饿或口渴恰好在内力恢复时点达到上限的状态核对该次恢复为 0 |
| 打坐与补给 | 分别在镇内、镇外探索时选择打坐，核对每次推进 4 个单位，饥渴满足且内力缺额足够时共回 12 点。用游戏时间 27、口渴度 9 且饥饿度较低的样例，核对只在第 28、29 个单位各回 3 点，第 30、31 个单位口渴封顶时内力恢复为 0 |
