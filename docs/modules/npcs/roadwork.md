# 镇口修路工地人物

## 工地管事

常驻镇口工地验料架旁。善恶值 **+50**，初始好感度 **0**。

工地管事常蹲在验料架旁查看石块大小。他性子实在，验料时仔细，对来干活的人态度随和。遇到道路临时挖开，他会告诉来人怎么绕过卸料点。

他接收石料管事发出的本轮工地石料。交付时核对当前轮次和物品，收下材料并结算差事。做完后可回采石场接下一趟。[搬运石料](../quests/design.md#搬运石料) · [石料管事](quarry.md#石料管事)

师门接引交付后，他在验料架旁兼售备料用的普通布。完成一轮石料搬运后，还可拿厚布护腕和普通布换扎腕护手。[货单](../items.md#交易) · [换物](../world.md#物品交换)

> 放验料架上吧。我对一下这批，验完就给你算这一趟。

### 工地管事的交互与对白

**交互分析。** 他总从脚下的路和手里的料说起。戒备时先问批次，熟了才聊他修路的心愿。玩家能问绕行与领料处，也能进入验料交付，结算取本轮和所带的石料。

对白偏向为 **偏善**。

**戒备**

- **问验料架在哪里** 「就我身旁这座。来交差先看是哪一批，料和这笔账要对得上。」
- **拿本轮记录核对交付** 「把你领的这一趟给我看。批次、石料都齐了，这边就能交。」 接续「查看石料交付」。
- **问还没领料该去哪里** 「去镇外采石场领料棚，找石料管事核对这一轮。他发料，我在工地验收。」
- **问如何绕开卸料处** 「走验料架外侧。车从卸料处进出，人靠边走就省得互相等。」

**平常**

- **问他怎么挑石块大小** 「先看厚薄，再用手摸平不平。路面上差出半指，推车的人也觉着颠。」
- **看看这一趟可以交了没有** 「我对一下单子，也看你带来的石料。两样齐全，就给你把这趟结了。」 接续「查看石料交付」。
- **问结完一趟能不能继续做** 「这一趟清了，便回领料棚问下一批。石料管事知道工地还缺哪样。」
- **问工地一天做到什么时候** 「手上那一段铺平就收。过路的人只管脚下好走，便算咱们干得妥当。」

**亲近**

- **聊缝补摊补过的袖口** 「叫你看出来了。缝补摊那位给我在袖口多压了一道线，比我自个儿瞎缝的耐用。」
- **请他一起验这趟料** 「来，同我把单子和石料一件件对过。你走这一趟，工钱也该算得明白。」 接续「查看石料交付」。
- **问他盼修好以后看到什么** 「下场雨，推车的人还能稳稳过镇口。让他们少下车推一回，我就觉得这路修得值。」
- **聊他头一回和石料管事共事** 「他一开口就催我数，我索性在每批头一块上画条白线。他一看就懂，后来再没把两趟叫混。」
