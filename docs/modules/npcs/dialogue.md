# NPC 交互与对白

## 善恶和好感

打开对话时，`game-core` 读取 NPC 配置的善恶值，以及该 NPC 对本档角色的当前好感度。两项均为 −100 至 100 的整数。善恶值决定对白偏向，当前好感度决定从该偏向中选哪一组。

| 数值 | 善恶偏向和口吻 | 好感对白组 |
| --- | --- | --- |
| −100 至 −20 | 偏恶，容易计较得失、偏袒或记旧账 | 戒备，少谈私事，先把来意和条件说清 |
| −19 至 +19 | 中立，按事实与眼前条件说话 | 平常，正常问候、说明事务或聊所在地点 |
| +20 至 +100 | 偏善，重承诺，愿意给来人一点提示 | 亲近，愿意聊来历、熟人和自己的想法 |

每位 NPC 按自己的善恶偏向编写戒备、平常、亲近三组，每组写四个话题。亲近后的游方郎中愿意把盘算说得更直白，仍要照他偏私、记旧账的性格来写。回到 NPC 菜单或读档重开对话时，以最新保存的好感度选组。

## 选择话题后的处理

玩家选择话题后看到对应对白。单纯问话播完返回该 NPC 的菜单。带有「接续」标记的选项在对白后进入下表对应的查看入口，按当前进度展示可做的事或缺少的条件。

带相貌条件的话题在当前好感组内按玩家保存的相貌档位筛选。[相貌](../character.md#相貌)

任务、买卖、挑战和领赏入口按各自的业务条件可用。接取、交付、购买、开战和领赏都由对应的确认动作结算。校场陪练的「确认校场安排」是校场口信的指定动作，只有满足接取与进度条件时才出现。单纯问话只读当前状态，好感变化由配置的剧情或任务事件提交。

必经任务的接取与交付在对话页独立显示，按对应任务与进度条件提示或办理。好感度和相貌选择聊天话题。例如师父的「师门安排」可以从对话页直接打开，学齐两项入门武学即可按师门接引的条件办理。[师门接引](../quests/design.md#师门接引)

商贩的「查看商品」和「换物」、顾炎武的「读书入门」、试武对手的「六派试艺」显示在各自 NPC 菜单的服务入口。三档好感共用进度门槛，四个对白话题依原规则选取。打开入口可查看货单、费用和缺项，确认时结算。[交易货单](../items.md#交易) · [物品交换](../world.md#物品交换) · [读书](../martial-arts.md#秘笈参悟与招式) · [试艺](../world.md#六派信物)

## 验收场景

- 善恶值取 −20、−19、+19、+20，分别核对偏恶、中立、中立、偏善。对老婆婆、中年妇人和游方郎中分别设置当前好感度为 −20、−19、+19、+20，核对戒备、平常、平常、亲近四种输入各打开对应的一组，组内都有四项，口吻符合各自的善恶设定。
- 模拟已有事件把某一 NPC 的好感度从 +19 增至 +20。回到该人的菜单应读到亲近组，重新读档也应读到同一组。检查其他 NPC 仍按各自保存的好感度选组。
- 用对师父好感分别处于戒备、平常、亲近的角色核对独立的「师门安排」。角色学齐两项入门武学时各组都可接取接引，任务达成后可通过同一入口交付。
- 用实战经验达到 5000 的角色找老婆婆查看家务和口粮，核对家务显示当前轮次或停派状态，口粮仍按四枚铜钱提供购买确认。让玩家在接取口信前后分别查看校场陪练的口信提示，核对指定问话只在任务条件满足时出现，选中该指定问话才推进联络进度。
- 用有待领奖励的角色向顾炎武查看待领账，核对展示合计。确认领取后核对一次发放与存档结清。重复查看和返回菜单只读取现有状态，任务、铜钱和好感度的变化由对应的确认动作或已配置事件产生。
