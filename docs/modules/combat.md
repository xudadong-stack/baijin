## 战斗页面

横屏战斗用文字描述双方交手。左侧显示双方状态，右侧用可滚动的战斗日志呈现过程，操作入口固定在右下。气血显示为「当前气血／有效气血上限」，受伤时另标原上限。内力显示为「当前内力／内力上限」。双方均使用精确数值。[横屏界面](../architecture.md#横屏界面)

校场切磋从陪练对话的「切磋 → 开始切磋」进入。当前陪练场次可以普攻，「招式」「物品」「更多」分别说明本场可用操作。战斗结束后，胜利页可查看本场完整日志并确认战利品，死亡页提供读取战前存档。[T10 验收](../task-overview.md#t10-验收)

战斗日志用简短的武侠叙事句带出关键结果。命中时写明实际伤害，暴击注明暴击，闪避、招架和防护挡尽各有能区分的描写。例「你一棍点中陪练肩头，造成 14 点暴击伤害。」守势、移舟等临时状态的生效和结束写在对应动作的日志中。首次生效写清持续范围，例如「守势生效，覆盖对手接下来的两次行动。」[防御招式](martial-arts.md#防御招式)

每套进攻武学的普攻和每个进阶招式各配三句原创动作描写。同一角色在本场再次使用同一动作时，按已结算回合中的使用顺序轮换。缺少对应武学时，普攻按徒手或武器类型选择通用描写。关键结果按实际结算接在动作后，完整文字和回合一起保存。[回合续玩](../adr/0002-resume-sparring-after-saved-round.md)

以棍类普攻为例，动作可以写成「你横转棍身，扫向陪练腰侧」「你收住棍尾，迎面一挑」「你踏前半步，棍尖指向陪练肩头」。如果对手侧身避过，接写闪避结果。若防护完全抵扣来招，写明护具挡尽和 0 点伤害。造成伤势时，文字说明有效气血上限的变化。

一次有效的玩家行动和本次实际发生的对手应对在同一回合内结算。通常整回合保存成功后才播放。需要选择获胜处置时，先播完最后一回合，再由玩家选择并保存终局。页面先播完玩家行动的文字，再默认等约一秒，自动显示对手已结算的应对。双方的气血、内力等读数随对应文字同步更新。播放期间锁住出招入口，玩家可以点「显示整回合」立即补齐本回合文字和最终读数。[正式挑战的获胜处置](#正式挑战的获胜处置)

战斗仍在进行时，继续游戏直接展示最近一次成功保存的完整回合与该回合结算后的读数，接着选择下一项行动。日志停在底部时随新文字滚动。玩家回看旧回合时保持当前阅读位置，有新文字时显示「回到最新」。[回合续玩](../adr/0002-resume-sparring-after-saved-round.md)

右下固定「普攻」「招式」「物品」「更多」四个入口。「招式」列出已满足学习等级或已通过参悟解锁的招式。「物品」列出背包持有且可在战斗中使用的物品。动态条件不符的条目保留在列表，标明原因，例如「需装备剑」「未运用守息功」「内力不足」或「气血已满」。选择满足条件的条目才会推进结算。交付师门接引后，「更多」提供吸气和加力。所有正式交战都在「更多」提供逃跑。[进阶招式](martial-arts.md#中期进阶招式参数) · [加力与吸气](#加力与吸气) · [逃跑](#逃跑)

点击「普攻」、选中可施展的招式或点「吸气」即可提交行动。用药和逃跑先显示确认，分别提示用药消耗和逃跑失败时对手应对，玩家确认后才提交行动。

在「更多 → 加力」设置下一次进攻的投入，查看该档的内力费用和攻击威力加成，再回到操作区选择普攻或进攻招式。设定的投入随下一次进攻一起提交，先检查招式和加力消耗的内力合计，再扣除内力并推进该次行动。操作区显示已选加力，并提供更改入口。该次进攻结算后可为下一次进攻重新设置。如果只设置加力就退出，继续游戏时从最近保存的完整回合重新选择加力。[加力与吸气](#加力与吸气)

决定胜负的最后一条动作文字显示后，获胜或角色被杀时自动进入相应的结果页，带上该条文字供阅读。师父和捕快的正式挑战获胜页提供处置选择。继续游戏时，已保存的待领取胜利结果与死亡结果直接打开各自结果页。被放过时返回交战地点，在探索日志显示战败处置。[正式挑战的获胜处置](#正式挑战的获胜处置) · [战败处置](#战败处置) · [获胜确认](items.md#普通掉落)

### 特殊招式文字演出

部分招式在战斗日志里分段出字。普攻和常规招式在同一段写出动作与结果。玩家与 NPC 共用播放规则，特殊招式的起手仍按该招的三句原创描写轮换。[NC2000 绝招文字参考](../reference/nc2000.md#nc2000-绝招文字表现)

| 招式 | 文字与状态 |
| --- | --- |
| 压锋斩、转桨棍 | 每招结算一次进攻。起手在一行内显示加粗的招名和动作描写。结算另起一行，按实际结果写出伤害、闪避、招架或防护挡尽。发生暴击或伤势时，在结算行注明 |
| 守势、移舟 | 生效和结束各占一行。生效行包含招名、起手、效果和持续范围。最后一次覆盖的对手行动结算时，显示带状态所属方的结束提示，例如「你的守势结束。」 |

起手文案按表中顺序使用，每句加上施展方的称呼。玩家用「你」，NPC 用界面上的名字。比如第一段显示「**压锋斩**　你沉肩压刃，刀锋直落。」第二段随本击结果显示「对手侧步让过刀锋，闪避成功。」守势起手时在同一行接写「接下来两次对手行动中，招架机会提高。」

| 招式 | 第一句 | 第二句 | 第三句 |
| --- | --- | --- | --- |
| 压锋斩 | 沉肩压刃，刀锋直落。 | 收紧刀势，斜斩而出。 | 踏定一步，借势挥出沉重的一刀。 |
| 转桨棍 | 转过棍尾，棍梢从侧面扫来。 | 将长棍往身侧一收，借回转之势横扫。 | 棍身一转，自下而上挑出。 |
| 守势 | 收肘稳住门户。 | 沉身凝神，留意对手的来势。 | 收住脚步，稳下架势。 |
| 移舟 | 脚下一错，身形斜移。 | 退开半步，借势转身。 | 脚尖一点，转向对手外侧。 |

特殊单击的起手与结算默认相隔约 300 毫秒。显示起手时更新施展方的内力，显示结算时更新受击方的气血、有效上限等读数。

当一招实际结算多次攻击时，起手显示一次，随后逐击显示结果和对应读数，直至实际完成的最后一击。整招计为施展方的一次行动。如果中途决出胜负，最后一击显示后进入对应的结果或处置。

每段取自同一次回合结算。点「显示整回合」时立即呈现本回合全部文字和最终读数。中途退出后，继续游戏展示最近一次已保存的完整回合。若已保存的结果结束了战斗，继续游戏按该结果进入相应界面。[回合续玩](../adr/0002-resume-sparring-after-saved-round.md)

## 气血、内力、受伤与疗伤

建角时记录当前气血与气血上限，用气血上限初始化有效气血上限。角色气血归零时，按战斗规则结算胜负。

**中期伤势与恢复上限。** 受伤可以降低有效气血上限，无伤时有效气血上限等于气血上限。自然恢复和吸气均以有效气血上限为限。被放过的角色保留已经受到的伤势。疗伤可以提高有效气血上限，最高恢复到无伤时的上限。

**致伤攻击先降有效上限。** 带致伤效果的招式只有在实际伤害大于 0 时才施加伤势。同一击同时造成伤害和伤势时，按以下顺序结算。

1. 按伤势降低有效气血上限，最低为 1。
2. 当前气血取原来的气血与新有效上限中的较小值。
3. 扣除本次实际伤害，当前气血最低为 0，再判定胜负。玩家气血归零时进入[战败处置](#战败处置)。

当前气血和有效上限均为 50 时，若上限降低 10 且实际伤害为 5，先把有效上限和当前气血降到 40，再扣 5 点。结算后当前气血为 35，有效上限为 40。

| 成长阶段规则 | 触发与结果 |
| --- | --- |
| 受伤 | 标有致伤效果的正式交战行动可造成伤势。同一击的伤势与伤害按上述顺序结算，数值始终满足 0 ≤ 当前气血 ≤ 有效气血上限 ≤ 气血上限 |
| 内力自然恢复 | 每经过 3 个游戏时间单位，先结算同一时点的饥饿度与口渴度。两项均低于上限时恢复 2 点内力，最高到内力上限。[补给与时间](character.md#角色成长与吃喝) |
| 内力 | 建角时基础上限为 `8 + 2 × 根骨`，当前内力为该上限。成长后加基本内功和当前运用内功的等级修正。上限变化时当前内力最高取新上限。主动动作在扣费前检查当前内力。[内功运用](martial-arts.md#运用与出招) |
| 打坐 | 探索时可随处选择打坐。一次推进 4 个游戏时间单位，每单位先结算饥渴，两项均低于上限时回 3 点内力，最高到内力上限。四个单位的内力用打坐量结算，气血按自然恢复处理 |
| 加力与吸气 | 加力为本次进攻额外支付内力，提高攻击威力。吸气消耗 4 点内力和一次行动，恢复最多 8 点当前气血。[内力动作](#加力与吸气) |
| 疗伤 | 使用对应药品或接受治疗时，先提高有效气血上限，再按效果恢复当前气血。成功使用药品时，同笔保存消耗与治疗结果 |

跨多个时间单位的行动逐个结算饥饿、口渴与恢复。正式交战中产生的伤势随战斗结果保存，可在退出后继续安排治疗。

角色在同一份存档中随成长和剧情条件使用内力动作及伤势规则。若受支持的旧存档结构缺少有效气血上限或内力字段，读取时保留已存当前气血，分别使用已存气血上限和角色建角内力初值补齐缺项。

**验收场景。** 令某角色气血上限为 50、有效上限为 35，验证自然恢复和吸气最多达到 35。以被放过的结果结束战斗时，核对有效上限仍为 35。使用一份疗伤散后，核对扣除一份药、有效上限升至 40，后续恢复可以达到 40。另在有效上限为 48 时用药，核对恢复至 50。在打坐途中让口渴度到上限，核对后续时段的内力恢复为零。

## 战斗规则

**开局回合试算。** 角色建角后可直接与陪练切磋。玩家选择普通攻击，先处理该动作及日志。陪练仍可行动时执行应对。每回合结束时保存结果，终局作为最后一回合保存。

**战斗时间。** 战斗以独立回合推进。场内的气血、内力和临时状态按双方行动结算。游戏时间、饥饿度、口渴度和自然恢复按探索规则中的时间动作推进。追缉按开战时的任务时限核对本场资格。[游戏时间](character.md#角色成长与吃喝) · [追缉时限](quests/design.md#追缉通缉犯)

- **命中与闪避。** 出手后用一次随机判定得到命中或闪避。闪避时记录闪避，以 0 点实际伤害结束这次攻击。命中后进入招架和后续伤害结算。
- **命中率与闪避率。** 以 `75 + 3 ×（攻方敏捷 - 守方敏捷）+ 攻方命中修正 - 守方闪避修正` 得到命中率的百分数，试玩上下限取 25% 与 95%。本次闪避率为 `100% - 本次命中率`。命中与闪避的额外修正按百分点计算。
- **命中与闪避的修正来源。** 攻方将武器、当前运用的进攻武学、招式和状态的命中修正相加。守方将基本轻功、运用轻功、护具和状态的闪避修正相加。开局普通攻击的招式命中修正取 0。[运用武学](martial-arts.md#运用与出招)
- **普攻威力。** 玩家与 NPC 共用 `4 + 攻方膂力 + 对应基本功威力加成 + 当前运用的进攻武学威力加成 + 武器攻击`。空手用拳脚，持武器用该类兵器的基本功和运用武学。缺项取 0。开局两项入门的徒手威力加成为 2 和 3，普通攻击的文字表现随运用武学变化。[八项基本功](martial-arts.md#八项基本功) · [门派武学](martial-arts.md#两条门派路线)
- **进攻招式。** 攻击威力为 `普攻威力 + 本招的威力加成 + 本次加力的威力加成`。普通攻击的招式加成取 0。进阶招式先核对运用武学、等级、武器与内力，再扣除内力并进入命中判定。[进阶招式参数](martial-arts.md#中期进阶招式参数) · [加力档位](#加力与吸气)
- **浮动幅度。** 普通攻击和各个进阶招式分别配置非负整数幅度 `A`，从 `−A` 至 `+A` 的所有整数中等概率取一个值。幅度为 0 时浮动值为 0，幅度为 2 时可取 −2、−1、0、+1、+2。
- **招架率。** 玩家角色和各 NPC 分别配置基础招架率。守方将 `基础招架率 + 基本招架修正 + 当前适用的招架运用修正 + 武器修正 + 状态修正` 相加，结果限制在 0% 至 50%。交付师门接引前，开局切磋用双方各自的基础招架率。接引交付后的战斗按等级和当前出手类别查表，无对应加成时取 0。
- **普通伤害。** 命中后按守方的招架率自动判定招架。招架成功，以 0 点实际伤害结束本次攻击。招架失败时，按招式配置抽取浮动值，再按点抵扣防护，得到 `普通伤害 = max(0, 攻击威力 + 本次浮动 - 守方防护)`。普通伤害为 0 时直接结算为 0 点实际伤害，大于 0 时进入[暴击判定](#暴击)。
- 防御招式扣费并占用本次行动，状态在对手应对前生效。状态持续次数按受增益方的对手完成的行动扣减。每个已保存回合保留双方内力、效果及剩余次数、文字日志和随机数进度，恢复后可作出下一次选择。[防御招式](martial-arts.md#防御招式)
- 按掉落表结算的场次在获胜时保存本场确定的掉落结果。待确认时继续游戏回到同一结果页。确认时同时保存战利品入背包、本场已确认标记与探索状态。一场只确认一次，新场次可以再次得到同种物品。[普通掉落](items.md#普通掉落)
- 符合任务条件的胜利还按任务配置加入必需物品，通过同一战利品结果确认领取。[任务必需掉落](items.md#任务必需掉落)

**开局难度试算。** 以每种合法加点学齐两项入门武学、满气血开场时对陪练的单场胜算都过半为平衡目标。样例陪练膂力 7、敏捷 7、根骨 5，气血上限 45，武学加成取 0，普攻威力为 11。试算基础招架率为玩家 5%、陪练 8%，普攻浮动幅度为 1。双方满气血，防护、额外命中和闪避修正、装备加成均取 0。对照试算的暴击率取 0%。枚举 231 种合法加点，学齐两项后最低胜率约为 66.7%。

**命中与闪避算例。** 攻方敏捷 10、守方敏捷 7 时，无额外修正的命中率为 84%。招式命中修正为 +5，守方闪避修正为 +12 时，命中率为 77%，闪避率为 23%。改用命中修正为 −10 的招式时，命中率为 62%，闪避率为 38%。已命中的攻击再按守方招架率结算。

**敏捷系数试算。** 沿用上述陪练和开局配置，仅改变每点敏捷差对应的命中百分点。三种系数下，学齐两项入门武学后的 231 种合法配点均有过半胜算。

| 每点敏捷差对应的命中百分点 | 学齐两项武学后的最低单场胜率 |
| --- | --- |
| 2 | 约 69.5% |
| 3 | 约 66.7% |
| 5 | 约 52.9% |

**伤害算例。** 攻击威力 15、防护 15，命中且招架失败后若浮动 +1，普通伤害为 1。浮动为 0 或 −1 时，实际伤害为 0。一招进阶招式若在威力 15 的普攻底数上加 5，则用 20 参加后续结算。招架成功时，本次攻击的实际伤害为 0，因此也免受这一击的伤势。

更换陪练参数或调整武学增益时，用同样条件重新核对所有合法配点的胜算。规则测试用固定随机输入覆盖玩家一击结束战斗、陪练反击结束战斗和双方闪避后进入下一回合。

| 成长阶段规则 | 前置与结算 |
| --- | --- |
| 轻功与招架修正 | 基本轻功及运用轻功计入守方闪避修正。成长阶段把基本招架、适用的招架运用、武器和状态修正计入招架率，日志记录招架结果 |
| 进阶招式与战斗用药 | 进阶招式校验等级组合、武器类型和内力。可在战斗中使用的药品按物品配置生效，成功使用占用一个回合 |
| 逃跑 | 所有正式交战都允许尝试。成功后返回交战入口并保存，失败后由对手应对。[逃跑公式](#逃跑) |
| 武器与护具 | 师门接引交付后，在探索时穿戴或卸下。武器按装备表提供攻击、命中和招架修正，护具提供防护与闪避修正。穿戴成功时保存装备状态。[装备细则](items.md#武器护具与背包) |
| 正式交战 | 由任务、剧情或主动挑战发起。任务按场次指定的结果判定进度，战败时使用[战败处置](#战败处置) |

**回合与掉落验收。** 用相同对手和固定随机输入比较学武前、习得基础武学后和习得门派武学后的普通攻击。打到一半重启，核对相同后续操作得到相同判定。胜利后在结果页确认前关闭应用，重启应看到同一掉落，重复确认后的累计入包数量等于一次领取。

### 加力与吸气

加力和吸气在师门接引交付时一起开放。加力默认投入 0 点。进攻提交时检查招式和加力的合计费用，支付后再判定命中。同一笔投入作用于这次进攻的威力计算。

| 加力投入的内力 | 本次进攻的威力加成 |
| ---: | ---: |
| 0 | 0 |
| 3 | +2 |
| 6 | +4 |

无加力时威力为 15 的攻击，投入 3 或 6 点内力会把威力提高到 17 或 19。若守方防护为 15，且本次命中、招架失败、浮动为 0，三档普通伤害分别为 0、2、4。

吸气要求当前内力至少有 4 点、当前气血低于有效气血上限。成功时扣 4 点内力、恢复 8 点气血，最多到有效气血上限，然后由对手应对。当前气血为 31、有效上限为 35 时，使用者先恢复到 35，再结算对手的行动。

### 逃跑

在正式交战中确认逃跑即占用本次行动。成功率的百分数取 `50 + 3 ×（己方敏捷 − 对手敏捷）+ 己方轻功修正 − 对手轻功修正`，最低 10%，最高 90%。轻功修正取基本轻功与当前运用轻功提供的闪避百分点之和。用一次等概率的 0 至 99 整数抽取，小于成功率时逃跑成功，其余结果由对手应对。

成功时结束本场并回到交战入口，随回合一起保存已结算的气血、内力、伤势与物品消耗。以逃跑结果结束时，任务按本轮已有进度继续。双方敏捷和轻功相同时成功率为 50%。己方敏捷高 3 点、轻功修正高 4 个百分点时为 63%。

### 暴击

攻击依次结算命中或闪避、招架、威力浮动与防护抵扣。玩家和 NPC 的普通伤害大于 0 时，按本次结算暴击率判定一次。普通命中的实际伤害取普通伤害，暴击的实际伤害取放大后的普通伤害。

实际伤害确定后，先按招式配置结算伤势，再一次性扣除本次实际伤害并判定胜负。暴击倍率只用于伤害。暴击结果和实际伤害写入战斗日志，与双方状态和随机数进度随回合一同保存。[伤势结算](#气血内力受伤与疗伤)

**名义暴击率。** 取 `5% +（攻方当前膂力 − 7）× 0.5 个百分点 + 当前运用的进攻武学等级加成 + 招式暴击修正`。取本次出手对应的武学和等级。武学或招式无相关加成时，该项取 0。普攻的招式暴击修正取 0。[武学等级加成](martial-arts.md#开局武学暴击加成) · [招式修正](martial-arts.md#中期进阶招式参数)

**结算暴击率。** 取 `名义暴击率 × 攻方幸运 ÷ 50`，结果限制在 0% 至 15%。玩家读取建角后保存的幸运，NPC 读取内容配置中的固定幸运。判定时将结算暴击率换算为万分数并向下取整，从 0 至 9999 等概率抽取一个整数。抽值小于换算后的阈值时触发暴击。例如 0.24% 对应阈值 24。[幸运生成](character.md#幸运)

膂力为 7 的角色运用三级回流棍法施展转桨棍时，武学和招式分别加 1 和 2 个百分点，名义暴击率为 8%。幸运为 10、50、90 时，结算暴击率分别为 1.6%、8%、14.4%。以幸运 10 为例，连续 6 次造成正伤害都未暴击的概率约为 90.8%。回流棍法升至五级后，幸运 90 的同一招达到 15% 上限。

**暴击伤害试算。** 暴击倍率取 1.5，实际伤害按 `ceil(普通伤害 × 1.5)` 向上取整。

威力 15、浮动 0、防护 6 时，普通伤害为 9，按试算倍率暴击后实际伤害为 14。防护达到 15 时，普通伤害为 0，本次攻击结算为 0 点实际伤害。适用致伤规则的攻击若有 10 点伤势、5 点普通伤害，暴击后实际伤害为 8。守方的当前气血与有效气血上限均为 50 时，先把两者降到 40，再扣 8，结算为 32 点气血、40 点有效气血上限。

## 正式挑战的获胜处置

[师父](npcs/training-yard.md#师父)和[捕快](npcs/town-hall.md#捕快)初见时即可由对话菜单发起正式挑战。玩家击倒对手后停止交手。结果页显示决定胜负的一击，并提供「放过」和「击杀」。

最后一回合在当前战斗中展示，等玩家选择处置后才一次保存。提交包含最后一回合、胜负与处置、相关任务和 NPC 状态变化，以及返回交战地点的探索状态。这两个挑战只记录胜负与处置。保存成功后回到探索，在日志显示处置结果。

选择击杀前，结果页列出本档会失去的服务、关闭的未交付委托和受影响的剧情路线。例如师门接引尚未交付且需要师父受理时，明确提示失去接引会关掉后续试武路线。提交击杀时，按本档已经完成的前置判断路线。丢失尚未满足的必需条件时，任务页和剧情入口显示路线已关闭及原因。[主线推进与路线关闭](world.md#声望通缉与结局)

| 选择 | 结算结果 |
| --- | --- |
| 放过 | 对手留在原地点，按其服务条件继续互动 |
| 击杀 | 对手在本档永久离场，关闭他的服务和未交付委托。扣减声望并触发通缉。已到账的奖励和已取得的物品属于玩家 |

若在处置提交成功前结束进程，继续游戏回到最近一次保存的完整回合，保留该时点的日志、双方状态和随机数进度。若第一回合就击倒对手，则回到开战时的状态。写入失败时提示重试同一份已选处置的结果。[存档提交](../architecture.md#内容与本地存档)

## 战败处置

NPC 的善恶值和对角色的好感度都是 −100 至 100 的整数，0 表示中立。善恶值与初始好感度由内容配置。游戏事件可以改变当前好感度，变化后的数值限制在同一范围并随进度保存。

切磋和正式交战在玩家战败时都按同一规则结算。把**对手的善恶值与对该角色的当前好感度相加**，总和大于或等于 0 时被放过，小于 0 时被杀。相同的两项数值始终得到相同结果，处置结果随终局保存。

| 善恶值 | 当前好感度 | 总和 | 战败结果 |
| --- | --- | --- | --- |
| 0 | 0 | 0 | 被放过 |
| +59 | −60 | −1 | 被杀 |
| +60 | −60 | 0 | 被放过 |
| −60 | +59 | −1 | 被杀 |
| −60 | +60 | 0 | 被放过 |

开局的[校场陪练](npcs/training-yard.md#校场陪练)善恶值为 +30、初始好感度为 0，新角色在这一关系下战败会被放过。

| 战败结果 | 结算与继续游戏 |
| --- | --- |
| 被放过 | 角色留在交战地点，保留战后的伤势和已结算消耗。当前气血以 1 点作为试玩值。提交结果后直接回到探索界面，日志说明对手放过了角色 |
| 被杀 | 保存死亡结果与战前存档。结果页提供「读取战前存档」，读档后恢复到触发本场战斗前可操作的探索状态，玩家可以先做别的事或再次挑战 |

开战时保留完整的战前进度。战斗中退出应用，从最近保存的回合继续。被杀后退出应用，再继续游戏时回到同一死亡结果页。读取战前存档恢复该时点的角色、位置、背包、游戏时间、任务和 NPC 关系。[战前存档决策](../adr/0004-keep-pre-battle-save.md)

**战败验收。** 对照表中样例验证两个数值各自升高时都能使总和从 −1 达到 0。被放过时核对探索位置、当前气血和伤势。死亡结果页重启后选择「读取战前存档」，核对可以从触发本场战斗前的状态重新行动。

| 处置后的结果 | 用不同存档尝试放过、击杀。核对末回合和处置只提交一次。重启后，放过时能按原条件互动，击杀时 NPC 离场、未交付委托关闭，同时读取同一声望和通缉结果。先模拟写入失败，再重试同一笔提交 |
| 路线关闭 | 用接引未交付的存档击倒师父。选择击杀前查到受影响的接引和后续门槛。提交后重启，任务页显示对应路线关闭及原因。另用已完成相关前置的存档核对路线按实际进度判断 |
| 战斗计时 | 在饥渴下一次增长和自然恢复的临界时点开战。完成多个回合并重启，核对游戏时间和补给读数仍对应开战时点，气血和内力与回合结算一致。回到探索后走到下一计时点，核对吃喝和恢复按时结算 |

### 成长阶段

- 中期以攻方敏捷 10、守方敏捷 7、守方闪避修正 +12 为样例。分别使用命中修正 +5、−10 的两个招式，核对命中率为 77%、62%。配置极端修正，验证试玩命中率下限 25% 与上限 95%。
- 中期验证进阶招式在普攻威力 15 上加本招威力 5，抵扣防护前按 20 参与浮动。用受控随机输入核对幅度 0 对应浮动值 0，幅度 2 可等概率取 −2、−1、0、+1、+2。
- 用[中期试算](#武学暴击与招式试算)的固定输入，核对点隙剑、压锋斩和转桨棍的浮动前威力依次为 19、23、20，命中率为 91%、73%、83%。在幸运 50 时，三招的结算暴击率为 5%、6%、8%。正式出招另按各自武学组合与武器条件实测。
- 中期固定膂力为 7、幸运为 50。回流棍法从三级升至四级后，转桨棍的结算暴击率由 8% 升至 8.5%，四级普攻为 6.5%。
- 用膂力为 7 的角色施展转桨棍，固定普通伤害大于 0。回流棍法三级、幸运为 1 时，结算暴击率为 0.16%，抽值 15 时暴击、16 时为普通命中。回流棍法五级、幸运为 90 时，结算暴击率为 15%，抽值 1499 时暴击、1500 时为普通命中。
- 用守势或移舟的第一个回合保存并重启，核对内力已扣、剩余一次状态，对手再行动一次后到期。状态生效期间重复尝试同招时，核对内力与行动未消耗。[防御招式](martial-arts.md#防御招式)
- 中期用固定随机输入让玩家和 NPC 分别自动招架带致伤效果的命中。成功时直接结算 0 点实际伤害，当前气血与有效气血上限均等于受击前的值。招架失败时继续结算浮动和防护。护具完全抵扣时也免受伤势。
- 中期用基础 5%、武学加 15 个百分点、武器加 5 个百分点、状态减 5 个百分点的样例，验证招架率为 20%。验证累计值为负时按 0%，累计值为 85% 时按 50%。
- 中期用有效气血上限为 50 的角色测试同一击致伤和扣血。上限降低 10、实际伤害为 5 时，当前气血起始为 50、30、3 的三个场景应分别结算为 35、25、0，有效上限均为 40。玩家气血归零时应触发战败处置。
- 中期在初始气血和有效气血上限均为 50 的样例中，用同一招造成 10 点伤势与 5 点普通伤害。固定暴击触发，按 1.5 倍试算核对先把有效气血上限及当前气血降到 40，再扣除 8 点实际伤害，得到 32 点当前气血和 40 点有效气血上限。
- 中期用气血上限 50、有效气血上限 35 的角色核对自然恢复和吸气最多恢复到 35。战败被放过时，核对保留伤势及已结算的战斗消耗。疗伤提高有效气血上限后，可继续恢复到新的上限。
