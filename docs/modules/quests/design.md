# 任务设计

[玩法模块索引](../../gameplay-rules.md) · [完整版本验收](../../acceptance.md) · [任务与经济](README.md)

本页的委托和支线纳入同一个完整版本。玩家在同一份存档里按区域、武学和剧情条件接取。建角后可找老婆婆接家务，找师父接校场口信，也可找陪练切磋。任务情节采用原创小镇内容。[奖励与平衡](rewards.md)

## 开局任务

### 老婆婆的家务差事

累计实战经验低于 5000 且手头没有未完成的家务时，打开老婆婆的对话，她从三种家务中等概率派一件，交代本轮差事并保存。重开对话或读档会恢复同一轮。完成对应地点的动作时，系统发放 50 铜钱、10 潜能和 20 实战经验，与本轮完成状态一起保存。做完后再次找她对话可触发下一轮。[老婆婆](../npcs/town-street.md#老婆婆)

累计实战经验达到 5000 时，老婆婆说明角色已小有名气，停止派发新家务。已经接取的家务可完成并领取该轮全额奖励。

| 家务 | 地点 | 完成动作 |
| --- | --- | --- |
| 扫地 | 老婆婆家屋内地面 | 选择「扫地」 |
| 挑水 | 南井旁 | 选择「打水」把井边水桶打满。井边也可选择「喝水」解渴 |
| 劈柴 | 柴堆旁 | 选择「劈柴」 |

家务与校场口信各自推进。用实战经验低于 5000、零铜钱、饥饿或口渴封顶的角色核对三种差事都能走完。补给步数按每种家务的路线和购粮位置测量。[补给预算](rewards.md#补给与铜钱)

### 校场口信

这是一次性的入门联络委托。玩家在校场西侧教习棚向[师父](../npcs/training-yard.md#师父)接取，去东侧练武区找[校场陪练](../npcs/training-yard.md#校场陪练)选择「确认校场安排」，再回师父处交付。交付一次发放 26 点潜能，足够习得基本拳脚和所选门派的入门拳法。师父提示可拜青衡门或渡川门并请教武学。[入门课表](../martial-arts.md#武学与修炼)

任务记录接取后的指定问话。新角色也可以直接找陪练切磋，或先去帮老婆婆做家务。

## 中期任务

### 师门接引

角色拜师并学齐两项入门武学后，可以向师父接取接引。选择「确认试武安排」了解对手和准备地点，然后向师父交付。交付时领取轻木棍和 20 铜钱，习得基本棍法 1 级与校场棍法 1 级，并将校场棍法设为首次的棍类运用。同一次提交保存物品、铜钱、已学武学、运用项和任务完成状态。按试算，行脚衣、布护腕和软底布鞋共花 16 铜钱，余 4 可买一份口粮。[试武棍法](../martial-arts.md#八项基本功)

接引交付后同步开放校场试武、装备穿戴、备战货单以及战斗中的加力和吸气。师父在校场西侧教习棚出售入门兵器，并指引玩家到小镇市街缝补摊找中年妇人买护具。行脚衣、布护腕和软底布鞋适用于各建角配点，可在试武前买齐并穿戴。试武交付后开放本门的兵器、内功和轻功课表，开放六派试艺，并增加进阶装备与钓具货单。[门派课表](../martial-arts.md#两条门派路线) · [内力动作](../combat.md#加力与吸气) · [交易货单](../items.md#交易) · [六派试艺](../world.md#六派信物)

### 师门演练

中期角色拜师并学齐两项入门武学后，师父请角色用已学武功检验一次。接取当前轮次后找陪练切磋，胜利记录保存后，本轮进入待交付。确认战利品并回师父处交付时，按样例发放 8 铜钱、4 潜能和 3 实战经验。同一轮结算后再接下一轮。

演练记录接取本轮以后的指定胜利。败退后，角色按战败处置继续，本轮仍可尝试。师门演练与校场试武可以并行，陪练的胜利只对应以陪练为目标的任务。[战败处置](../combat.md#战败处置)

### 校场试武

师父安排角色与[试武对手](../npcs/training-yard.md#试武对手)正式交手。角色先接取任务，再到校场北侧试武台找试武对手选择「参加试武」。胜负、首胜经验和任务掉落都按本场结算。首次胜利发 5 点实战经验，当场的试武凭牌 ×1 按任务条件 100% 掉落。

待确认结果页保存着本场凭牌。确认入包后，任务转为待交付，后续胜利按普通掉落表结算。向师父交付时扣除一枚，并发放 8 铜钱、8 潜能、3 实战经验。本次首胜和任务交付合计发放 8 点实战经验。败退时可以补给后重试，角色被杀时可读取战前存档恢复交战前的任务进度。[任务必需掉落](../items.md#任务必需掉落) · [任务奖励](rewards.md#任务奖励)

### 备副护腕

中期向师父接取的一次性寻物支线。师父需要一件可交的布护腕，玩家可从已有战利品或商店取得。交付时扣除一件布护腕、发放一件厚布护腕，并保存已交付状态。背包只有一件布护腕且正在穿戴时，可用数量为零，任务提示先卸下或再找一件。按试算，换上厚布护腕后，该部位增加 1 点防护，闪避修正降低 6 个百分点。[装备数值](../items.md#武器与护具) · [寻物交付规则](README.md#任务并行与交付)

### 搬运石料

交付师门接引后，镇外采石场和镇口修路工地开放。玩家向[石料管事](../npcs/quarry.md#石料管事)接取一轮差事，同时收到工地石料 ×1，代表一批备好的石料。领料时保存本轮进度和背包，任务页提示到镇口找[工地管事](../npcs/roadwork.md#工地管事)交付。

带着本轮石料抵达工地后，任务进入待交付。向工地管事交付时核对当前轮次与石料，扣除一批并发放试算奖励 100 铜钱、20 潜能和 40 实战经验。扣料、发奖和本轮完成状态一起保存。交付后可回采石场领下一批。

工地石料是关键物品，只用于对应轮次的交付。途中重启后恢复同一批石料和运输进度。同一轮的领料与交付各结算一次。累计实战经验达到 5000 的角色也可按上述条件接取搬运差事。[任务奖励](rewards.md#任务奖励) · [补给预算](rewards.md#补给与铜钱)

### 拜访镇民

村长所在区域开放且没有进行中的拜访时，打开村长的对话即触发一轮，村长给出镇民的姓名和常在地点。完成本轮指定谈话时，任务结束，系统发放 40 铜钱、12 潜能、20 实战经验。再次与村长对话可触发下一轮。[村长](../npcs/town-hall.md#村长)

### 寻物

交付师门接引后，打开中年妇人的对话即触发一次寻物，她会请玩家带来一份普通布。接取前已有的布计入可用数量，也可到镇口工地验料架旁向工地管事按 4 铜钱一份购买。再次与她对话并选择「交付普通布」时重验可用数量，扣除一份布、完成任务并发放 75 铜钱、15 潜能、30 实战经验。寻物可与村长的拜访同时进行。[中年妇人](../npcs/town-street.md#中年妇人) · [物品价格](../items.md#消耗品材料与工具) · [任务奖励](rewards.md#任务奖励)

### 追缉通缉犯

交付校场试武后，在镇公所东侧值房与捕快对话，满足派发条件时直接触发一轮追缉。捕快告知本轮通缉犯的姓名和出没地点。角色在有效期内进入该轮指定的正式交战，胜利结算时完成任务，经验与潜能随胜负一起保存，并在战斗结果中显示。[捕快](../npcs/town-hall.md#捕快)

- **档位。** 首轮为第 1 档。完成第 1 至第 9 档后，下一轮升一档。完成第 10 档后，下一轮从第 2 档开始。每档匹配对应强度的正式交战，强度系数采用 [NC2000 十档表](../../reference/nc2000.md#nc2000-捕快追缉)。
- **目标。** 接取时按本轮档位从已配置的目标与出没点组合中抽取一组，保存该轮目标、地点和对手配置。对话、任务页和续玩都读取本轮记录。各档的实际候选组合与武学、装备、打法待补。
- **计时。** 保存本轮接取时的游戏时间。已完成且距本轮接取超过 300 个游戏时间单位时，再次对话可触发下一轮。进行中的任务在距接取达到 1200 个游戏时间单位时过期，再找捕快会降一档重派，最低第 1 档。开战时核对本轮目标和资格，战斗用独立回合计数，因此在第 1199 个单位开打后仍可打完这场。[战斗时间](../combat.md#战斗规则)
- **奖励。** 接取时等概率抽取 0 至 79 的整数，本轮实战经验为 `(80 + 抽出的整数) × 档位`，潜能为这笔经验除以 4 后向下取整。本轮目标、档位、接取时间和奖励一起保存。获胜结算时发放两项奖励并保存轮次完成状态，同一轮结算一次。[任务奖励表](rewards.md#任务奖励)
- **战利品。** 按本轮通缉犯所在档位抽取一组普通掉落，和胜负一起保存，确认结果后入包。[追缉普通掉落组](../items.md#普通掉落权重)

对手气血和内力用此前确认的固定基准试算。第 5 档气血上限 80、内力上限 40，按十档系数换算这两项。武学、装备和出手策略按档位分别配置。

| 档位 | 系数 | 气血上限 | 内力上限 |
| ---: | ---: | ---: | ---: |
| 1 | 80% | 64 | 32 |
| 2 | 85% | 68 | 34 |
| 3 | 90% | 72 | 36 |
| 4 | 95% | 76 | 38 |
| 5 | 100% | 80 | 40 |
| 6 | 105% | 84 | 42 |
| 7 | 110% | 88 | 44 |
| 8 | 115% | 92 | 46 |
| 9 | 120% | 96 | 48 |
| 10 | 125% | 100 | 50 |

## 剧情委托

### 查杀指定人物

药材纠纷中选择帮游方郎中私下处置争端后，郎中在对话中直接派发一次查杀，点名一位已经在剧情出现的 NPC。接取后由玩家击杀指定人物，确认击杀结果时完成任务，系统发放 40 潜能、80 实战经验和疗伤散 ×2。[游方郎中](../npcs/town-street.md#游方郎中) · [剧情选择与状态](../world.md#声望通缉与结局)

这场一次性正式交战按追缉第 1 档的难度配置。80 点经验取该档奖励的下限。[委托经验对照](rewards.md#委托经验对照)

## 任务提示

对话派发的任务在 NPC 交代差事时进入任务页，显示目标、地点和当前进度。挑水显示「去南井打水」，打满后提示完成和到账数额。确有后续交付步骤的任务才显示交付对象。中年妇人的寻物在布料可用时提示交布，校场口信取得消息后提示「回教习棚找师父交付」。重启后按存档恢复同一轮次和进度。[任务并行与交付](README.md#任务并行与交付)

## 任务流程核对

| 场景 | 预期结果 |
| --- | --- |
| 接到挑水后先去井边喝水 | 喝水降低口渴度，挑水仍进行中。选择「打水」后当场完成并发奖 |
| 实战经验低于 5000，扫完地后在原地重启 | 本轮仍为已完成，余额只有一份奖励的增量。再次与老婆婆对话时触发下一轮 |
| 实战经验 4980 时完成家务 | 本轮全额发奖，实战经验达到 5000。再与老婆婆对话时，她说明停止派活的原因 |
| 已接家务后从其他来源达到 5000 实战经验 | 本轮可做完并获得全额奖励。再次对话时老婆婆停止派发新家务 |
| 同时进行家务差事和校场口信 | 两项进度各自保存。家务做完即发报酬，口信可继续推进并单独领取潜能 |
| 先与陪练闲谈，再向师父接校场口信 | 接取后选择指定问话，可回师父处领一次潜能 |
| 只学会一项入门武学时找师父 | 接引提示还缺另一项。学齐后可以接引，交付时领一次木棍和准备预算 |
| 两项入门武学已学齐，接引尚未交付 | 师父提示先完成接引。接引交付后可以接取校场试武 |
| 在校场口信达到待交付后关闭应用 | 继续游戏时任务页提示回师父处交付，与师父对话可完成交付 |
| 演练中途退出或先有一场旧胜利 | 退出后按已存回合续玩。任务核对本轮接取后的胜利 |
| 试武胜利的普通掉落为空 | 本场仍有凭牌。确认前重启显示同一凭牌。确认后任务转为待交付，重复确认或在待交付时再胜均只有一枚 |
| 首胜后交付试武 | 胜利获首胜经验，交付时扣凭牌并另发任务奖励，重启后两笔分别可核对 |
| 穿着唯一一件可交付的布护腕 | 支线提示缺可用护腕。卸下再交付，重启后核对布护腕扣一件，厚布护腕增加一件，任务已交付 |
| 搬运石料途中重启并再次找石料管事 | 读出同一轮和一批工地石料。任务页显示镇口的工地管事，交付后方可领下一轮 |
| 向工地管事交料后重复提交 | 本轮只扣一批石料，三项奖励和完成标记均结算一份 |
| 先与村长将要指定的镇民交谈，再触发拜访 | 任务页指向该镇民及其常在地点。触发后完成指定对话才当场结算 |
| 接寻物前持有一份普通布，在交付前用掉 | 任务重新按可用数量判定，显示缺一份普通布。补齐后可向摊主交付 |
| 先后完成一轮拜访和一次寻物 | 两次各自到账，奖励共计 115 铜钱、27 潜能、50 实战经验，重启复核余额 |
| 交付校场试武后触发追缉，期间赢下其他交战 | 任务继续指向通缉犯。赢得本轮指定正式交战才当场完成并结算 |
| 第 5 档追缉抽出的整数为 79，获胜后重启 | 本轮已完成，到账 795 实战经验、198 潜能，重开战斗结果时累计仍为一份 |
| 选择帮郎中触发查杀，指定人物仍存活 | 任务页显示查杀目标。确认玩家的指定击杀时完成并发奖，重启核对 40 潜能、80 实战经验、疗伤散 ×2 仅到账一次 |
