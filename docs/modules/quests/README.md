## 委托与经济

委托从可接取进入进行中，达到目标后转为待交付。向任务指定对象交付时，按任务配置当场发放奖励或登记待领奖励，与已交付标记一同保存。校场口信从师父处接取，向陪练确认消息后回师父处交付。潜能来自任务奖励，用于习得和提升武学。[累计领赏](#累计领赏)

**开局家务差事。** 累计实战经验低于 5000 时，向老婆婆接取一轮家务，在扫地、挑水和劈柴中选择本轮目标并保存。角色在指定地点完成对应动作后，任务进入待交付。交付发放 50 铜钱、10 潜能和 20 实战经验，三项奖励与本轮完成状态同时保存。累计实战经验达到 5000 后停止派发新家务。已经接取的家务可以完成并领取全额奖励。[家务地点和动作](design.md#老婆婆的家务差事) · [奖励表](rewards.md#任务奖励)

已接取的三种家务在铜钱为零或饥饿、口渴已到上限时也能完成。井边的「打水」推进挑水任务，「喝水」降低角色口渴度。

**中期搬运差事。** 交付师门接引后，向石料管事接取本轮并领取一批工地石料。送到镇口后，向工地管事交料并领取该轮报酬。工地石料是对应轮次的关键物品。本轮交付后可以领下一批。[搬运石料](design.md#搬运石料)

| 任务类型 | 达成条件 | 交付结果 |
| --- | --- | --- |
| 寻物 | 背包持有指定数量的可交付物品 | 交付时同步扣除对应数量，按任务配置发放奖励或登记待领 |
| 联络 | 接取后按任务要求与目标 NPC 对话 | 核对联络进度，按任务配置发放奖励或登记待领 |
| 缉捕 | 接取后赢得指定的正式交战 | 核对指定胜利记录，再发放本次交付奖励 |
| 查杀 | 接取后由玩家击杀指定 NPC | 核对指定目标的死亡记录，登记本次待领奖励 |
| 师门任务 | 角色满足门派归属与任务前置，并完成指定目标 | 交付可给潜能、实战经验或道具，具体奖励随任务配置 |

村长的拜访、中年妇人的寻物、捕快的缉捕和游方郎中的查杀均在同一版本开放，接取条件与交付对象见[任务设计](design.md)。

**实战经验。** 新角色从 0 起，开局通过交付家务积累实战经验。中期可通过师门演练、石料搬运、捕快追缉等任务继续取得，也可从指定正式挑战的首胜获得。追缉按本轮档位计算并在交付时结算。拜访、寻物和郎中查杀的经验在复命时登记，到小镇领赏处领取时才计入累计实战经验。高阶请教检查已到账的实战经验，学习消耗潜能。首次挑战胜利时同时保存经验增加与首胜标记。同一角色再次赢得同一挑战时，首胜经验已结清。实战经验也可作为后续挑战的候选前置条件。[追缉规则](design.md#追缉通缉犯) · [累计领赏](#累计领赏)

**验收场景。** 先找陪练说话再接校场口信，角色仍需接取后确认消息。花完初始铜钱后完成两轮家务，核对每轮三项奖励只结算一次，用所得购买口粮。中期用潜能足够、实战经验不足的角色尝试高阶请教，核对经验缺项和潜能余额。再次赢得同一指定挑战时核对实战经验未重复增加。交付中年妇人的寻物时核对扣物和待领奖励一同保存。

**家务验收。** 用实战经验低于 5000、零铜钱且饥饿与口渴已到上限的角色分别验证三种家务。接到挑水时，到井边先喝水，核对本轮仍为进行中，再打水并重启，核对仍是挑水、进度为待交付。交付时检查增加 50 铜钱、10 潜能和 20 实战经验。重启并重复交付时，累计增量应等于一轮奖励。买一份口粮后余额为 46 枚，食用后饥饿度下降。用 4980 实战经验交付一轮，核对经验达到 5000 且老婆婆停止派活。

### 任务并行与交付

- **任务并行。** 校场口信、家务差事及其他任务各自记录进度。同一重复任务同时只有一轮，交付后按该任务的接取条件判定下一轮。校场口信进行中也能交付家务。
- **寻物交付。** 接取前已有的普通寻物道具计入可用数量。可用数量变化时，按当前数量重判待交付状态，对话和胜利等已达成的目标各自记录。交付时重验数量，将扣物、交付状态和奖励发放或登记结果一起保存。若两个任务各需一份布且角色只有一份，玩家可以先交其中任一项，另一项随后回到进行中并提示缺一份。
- **联络与交战记录。** 指定交谈及胜利在接取后、任务指定的目标阶段发生时才记入当前进度。需要取得战斗掉落的寻物目标在确认领取、物品入背包后按可用数量判定。[任务必需掉落](../items.md#任务必需掉落)
- **关键物品的用途。** 配置为关键物品的信物只能通过对应任务或剧情动作使用。需要扣除关键物品时，物品扣除与任务或剧情推进一并保存。普通寻物道具按自身配置处理。
- **重复任务的成长奖励。** 指定的可重复任务可配置每轮交付获得潜能和实战经验。该轮交付状态与对应奖励一同保存，同一轮只结算一次。例如每轮给 4 点潜能和 3 点实战经验，完成十轮并领取后共得 40 点潜能和 30 点实战经验。
- **首胜经验与任务经验。** 同一场胜利可以同时满足挑战首胜条件和任务目标。挑战经验在首胜时发放，任务经验按对应轮次的奖励方式领取，两笔可以累计。例如首胜发 5 点、领任务奖励再得 3 点，共获得 8 点实战经验。后续同一挑战的胜利可以推进新的任务轮次，按该轮配置领取交付奖励。

### 累计领赏

村长的拜访、中年妇人的寻物和游方郎中的查杀采用累计领赏。向各自的交付对象复命时，按本轮配置确定报酬。将任务标记为已交付、扣除应交物品，并一起保存该轮待领奖励。每轮只登记一笔。玩家满足接取条件时，可以继续接其他任务或开始同一任务的下一轮。

待领奖励随存档保留至领取，可跨游戏时间和重启继续累积。任务页显示待领合计，并提示到镇公所外间找顾炎武领取。[顾炎武](../npcs/town-hall.md#顾炎武)

玩家在柜台与顾炎武对话确认后，按登记的数量一次发放全部待领奖励。铜钱和潜能进入各自余额，实战经验加入角色的累计实战经验，物品按种类合计后入背包。发放与结清这批记录一同保存，重复确认同一批只发放一次。当前的余额、可用物品和高阶请教条件按已经到账的资源计算。[任务奖励表](rewards.md#任务奖励) · [验收规则](../../acceptance.md#成长阶段验收)

## 验收场景

### 开局

| 场景 | 检查步骤与通过条件 |
| --- | --- |
| 三种家务的目标 | 分别接取扫地、挑水和劈柴，核对任务页指向院子、水井和柴堆。用挑水验证先喝水时进度仍为进行中，打水后转为待交付。达成目标后重启，核对本轮家务和待交付状态 |
| 重复差事与购粮 | 用零铜钱、零实战经验的角色向老婆婆接取并交付两轮家务，核对累计获得 100 铜钱、20 潜能和 40 实战经验。重复提交或重启后按已交付轮次核对累计奖励。按试算价 4 铜钱买一份口粮，核对余额为 96 枚 |
| 家务派活门槛 | 4999 实战经验时可接新家务，完成并交付后经验为 5019。4980 实战经验时交付一轮，核对全额领赏并达到 5000。两种角色再次与老婆婆对话时，她说明停止派活的原因，同时可按 4 枚铜钱购买口粮。重启后核对这两项服务的反馈 |
| 达到门槛时交付已接家务 | 在实战经验低于 5000 时接取一轮家务，交付前从其他任务获得经验达到 5000。完成该轮并向老婆婆交付，核对三项奖励一次性保存。再次对话时老婆婆停止派发新家务 |
| 委托进度与奖励 | 先与陪练对话，再向师父接取校场口信，核对接取时为进行中。接取后重新与陪练确认消息，委托转为待交付。回师父处交付后核对任务标记与潜能。重复交付或重启继续时，累计所得为一份交付奖励 |
| 任务并行 | 按校场口信进行中和家务差事待交付准备存档，重启后读出两项各自的进度。交付家务领取本轮奖励，再完成并交付校场口信领取其潜能。当前家务尚待交付时重复尝试接取，核对只有一个当前轮次 |
| 任务页 | 从师父对话接校场口信，核对任务页指向陪练。确认消息后在交付前重启，任务页应提示回师父处交付。与师父对话可完成交付 |

### 成长阶段

- 中期学齐两项武学后，以对师父好感度为 0 的存档进入对话并办理接引。核对校场试武提示先交付师门接引，接引交付后可以接取。使用备副护腕支线验证穿戴件的占用、交付时扣除一件布护腕和获得一件厚布护腕。[任务流程核对](design.md#任务流程核对)
- 中期用已交付师门接引、实战经验为 5000 的角色接取搬运石料。重复接取后核对只有同一轮的一批石料。途中重启后按任务页前往镇口工地。验证由工地管事收货，石料扣除与本轮报酬同步保存。重复交付和重启时按一轮计奖，交付后回采石场可接下一轮。按试算交付两轮共得 200 铜钱、40 潜能和 80 实战经验。[搬运石料](design.md#搬运石料)
- 同时接取村长的拜访与中年妇人的寻物，分别核对下一步和交付对象。用接取前后的交谈核对拜访只有接取后的指定对话计入进度。用接取前已有的布核对寻物可以交付，交付前耗掉布时应提示缺一份。补齐后交付并重启，核对扣除一份布，待领报酬为 50 铜钱、10 潜能、20 实战经验。再持一份普通布找中年妇人，核对寻物已交付，同一任务只结算一笔。[拜访镇民](design.md#拜访镇民) · [寻物](design.md#寻物)
- 从待领合计为零开始，交付一轮拜访和一次寻物，核对待领合计为 90 铜钱、22 潜能、40 实战经验。复命时三项入账增量均为零。随后接取并交付第二轮拜访，待领合计为 130 铜钱、34 潜能、60 实战经验。推进游戏时间并重启后，按任务页提示找镇公所外间的顾炎武，核对一次取得这三项合计。随后重启核对该批已结清，重复领取的增量为零。[累计领赏](#累计领赏)
- 测量常见拜访路线从接取到复命的往返与补给耗时，按每轮 20 点实战经验与搬运比较单位时间收益。以搬运试算的每单位 1 点为基准，记录拜访路线是否常短于 20 个游戏时间单位。[拜访耗时试算](rewards.md#补给与铜钱)
- 校场试武待交付时找捕快，核对追缉任务的前置条件。试武交付后接取第 1 档追缉。重新对话及重启后，核对轮次、目标、地点、对手配置和奖励一致。在其他交战中获胜时进度保持进行中，赢下本轮指定交战后转为待交付。用第 1、5、10 档核对气血与内力上限由固定基准换算。[追缉通缉犯](design.md#追缉通缉犯)
- 固定追缉的抽取值为 0 和 79，核对第 1 档的实战经验、潜能分别为 80、20 和 159、39，第 10 档分别为 800、200 和 1590、397。另用第 5 档抽取 79 的轮次测试发奖时点。获胜后在复命前重启，核对本轮悬赏尚待交付。向捕快交付时获得 795 实战经验和 198 潜能，重复交付及重启后的累计增量仍为一份。
- 追缉已交付且距该轮接取恰好 300 个游戏时间单位时，向捕快对话核对时间提示。推进至 301 时可接下一轮。用已交付的第 1、9、10 档分别验证下一轮为第 2、10、2 档。
- 追缉进行中且距接取恰好为 1199 个游戏时间单位时开战，完成多回合并重启续战，核对获胜可进入待交付。用仍在探索的角色到第 1200 个单位再尝试开战，核对本轮过期，找捕快按规则降档重派。第 5 档降至第 4 档，第 1 档重派仍为第 1 档。另用已达成待交付的轮次跨过 1200，核对仍可正常领取已确定的本轮奖励。
- 配置一项在交付时每轮发 4 点潜能和 3 点实战经验的重复任务。完成两个不同轮次并各自交付，核对总共得到 8 点潜能与 6 点实战经验，重复提交同一轮交付时按一轮计入。
- 用接取前已有的一份布同时满足两个寻物任务的数量条件。任选其一交付，重启后核对扣除一份布，并按该任务的配置结算一笔报酬。另一项处于进行中并提示还缺一份。另用一件可交付的护腕验证穿戴后数量不足、卸下后可交付。用接取前后的交谈和胜利记录核对事件目标，符合指定任务阶段的操作计入当前轮次。
- 在进行中的任务要求赢得某个正式挑战时完成首胜。按样例在胜利时发 5 点实战经验，交付任务再发 3 点，累计为 8 点。下一轮重复任务时核对只有本轮配置的交付奖励，同一挑战的首胜经验累计仍为 5 点。

### 探索与剧情

- 用已有 90 铜钱、22 潜能、40 实战经验待领的存档，在药材纠纷中选择帮游方郎中，核对查杀入口、指定目标与交付对象。由玩家击杀目标后向郎中交付，重启核对本分支已交付一次，待领合计为 90 铜钱、62 潜能、120 实战经验和疗伤散 ×2。再次尝试交付时，核对查杀只有一笔报酬。在小镇领赏处一次领完，核对相应资源和药品入账。另走药材纠纷的其他剧情选择，核对查杀只在帮郎中的对应分支开放。[查杀指定人物](design.md#查杀指定人物)

### 领赏存档

- 模拟累计领赏提交失败和提交成功后立即退出。失败时读档仍显示整批待领取，重试后取得一次合计。成功后读档显示整批已结清，已到账的资源与入包物品各累计一份。
