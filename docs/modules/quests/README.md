## 委托与经济

支持对话派发的委托在条件满足时，打开发布人的对话即进入进行中。家务、拜访、追缉和查杀在目标事件成功时完成并发奖。寻物要由玩家确认交物，扣物时发放奖励。校场口信取得消息后，需返回师父处交付。潜能来自任务奖励，用于习得和提升武学。[任务设计](design.md)

**开局家务差事。** 累计实战经验低于 5000 且没有未完成的家务时，与老婆婆对话会从扫地、挑水和劈柴中随机派一件。指定动作完成时获得 50 铜钱、10 潜能和 20 实战经验，三项奖励与完成状态一起保存。达到 5000 后停止派发，已经接下的家务仍可完成并获得全额奖励。[家务地点和动作](design.md#老婆婆的家务差事) · [奖励表](rewards.md#任务奖励)

已接取的三种家务在铜钱为零或饥饿、口渴已到上限时也能完成。井边的「打水」推进挑水任务，「喝水」降低角色口渴度。

**中期搬运差事。** 交付师门接引后，向石料管事接取本轮并领取一批工地石料。送到镇口后，向工地管事交料并领取该轮报酬。工地石料是对应轮次的关键物品。本轮交付后可以领下一批。[搬运石料](design.md#搬运石料)

| 任务类型 | 达成条件 | 结算时机 |
| --- | --- | --- |
| 寻物 | 背包持有指定数量的可交付物品 | 确认交物后扣除物品并发奖 |
| 联络 | 接取后完成指定谈话 | 拜访镇民在谈话达成时发奖，需传话的校场口信在交付时发奖 |
| 缉捕 | 接取后赢得指定的正式交战 | 胜利结算时发奖 |
| 查杀 | 接取后由玩家击杀指定 NPC | 击杀结果确认时发奖 |
| 师门任务 | 角色满足门派归属与任务前置，并完成指定目标 | 交付可给潜能、实战经验或道具，具体奖励随任务配置 |

村长的拜访、中年妇人的寻物、捕快的缉捕和游方郎中的查杀属于完整版本计划。接取和结算条件见[任务设计](design.md)。

**实战经验。** 新角色从 0 起，通过完成家务取得实战经验。中期可通过师门演练、石料搬运、拜访、寻物、追缉等任务继续取得，也可从指定正式挑战的首胜获得。追缉经验按本轮档位计算，在胜利结算时到账。高阶请教检查已到账的实战经验，学习消耗潜能。首次挑战胜利时同时保存经验增加与首胜标记。[追缉规则](design.md#追缉通缉犯)

**验收场景。** 先找陪练说话再接校场口信，角色仍需接取后确认消息。花完初始铜钱后完成两轮家务，核对每轮三项奖励只结算一次，用所得购买口粮。中期用潜能足够、实战经验不足的角色尝试高阶请教，核对经验缺项和潜能余额。再次赢得同一指定挑战时核对实战经验未重复增加。交付中年妇人的寻物时核对扣物和奖励到账一同保存。

**家务验收。** 用实战经验低于 5000、零铜钱且饥渴已满的角色验证三种家务。挑水时先喝水，本轮仍进行中。打水后在井边核对奖励和完成状态，再重启核对只有一份奖励。之后买一份口粮，余额应为 46 铜钱。

### 任务并行与交付

- **任务并行。** 任务各自记录进度。同一重复任务同时只有一轮，当前轮结束后按该任务的派发条件判定下一轮。
- **寻物交付。** 接取前已有的道具计入可用数量，有足量道具时显示可交付。交付时重验数量，将扣物、任务完成与发奖一起保存。若两个任务各需一份布且角色只有一份，可先交其中一项，另一项随后回到进行中并提示缺一份。
- **联络与交战记录。** 指定交谈及胜利在接取后、任务指定的目标阶段发生时才记入当前进度。需要取得战斗掉落的寻物目标在确认领取、物品入背包后按可用数量判定。[任务必需掉落](../items.md#任务必需掉落)
- **关键物品的用途。** 配置为关键物品的信物只能通过对应任务或剧情动作使用。需要扣除关键物品时，物品扣除与任务或剧情推进一并保存。普通寻物道具按自身配置处理。
- **重复任务的成长奖励。** 指定的可重复任务可配置每轮交付获得潜能和实战经验。该轮交付状态与对应奖励一同保存，同一轮只结算一次。例如每轮给 4 点潜能和 3 点实战经验，完成十轮并领取后共得 40 点潜能和 30 点实战经验。
- **首胜经验与任务经验。** 同一场胜利可以同时满足挑战首胜条件和任务目标。挑战经验在首胜时发放，任务经验按对应轮次的奖励方式领取，两笔可以累计。例如首胜发 5 点、领任务奖励再得 3 点，共获得 8 点实战经验。后续同一挑战的胜利可以推进新的任务轮次，按该轮配置领取交付奖励。

## 验收场景

### 开局

| 场景 | 检查步骤与通过条件 |
| --- | --- |
| 三种家务的目标 | 打开对话直接触发一轮。分别核对三个目标的任务提示。重复对话、重启继续后仍是原轮次和原目标。先喝水时挑水仍进行中，打水后当场完成并发奖 |
| 重复差事与购粮 | 用零铜钱、零实战经验角色完成两轮家务，核对共得 100 铜钱、20 潜能和 40 实战经验。重复提交和重启后余额一致。买一份口粮后余 96 铜钱 |
| 家务派活门槛 | 4999 时对话能触发新家务，完成后经验为 5019。4980 时完成一轮后经验为 5000。两种角色再次对话时均停止派活，口粮仍可购买 |
| 已接家务后达到门槛 | 先触发家务，再从其他任务获得经验并达到 5000。完成本轮时保留全额奖励，再次对话时停止派活 |
| 委托进度与奖励 | 先与陪练对话，再向师父接取校场口信，核对接取时为进行中。接取后重新与陪练确认消息，委托转为待交付。回师父处交付后核对任务标记与潜能。重复交付或重启继续时，累计所得为一份交付奖励 |
| 任务并行 | 家务和校场口信进行中时重启，两项分别恢复。家务完成即发奖，口信继续推进并交付领潜能 |
| 任务页 | 从师父对话接校场口信，核对任务页指向陪练。确认消息后在交付前重启，任务页应提示回师父处交付。与师父对话可完成交付 |

### 成长阶段

- 中期学齐两项武学后，以对师父好感度为 0 的存档进入对话并办理接引。核对校场试武提示先交付师门接引，接引交付后可以接取。使用备副护腕支线验证穿戴件的占用、交付时扣除一件布护腕和获得一件厚布护腕。[任务流程核对](design.md#任务流程核对)
- 中期用已交付师门接引、实战经验为 5000 的角色接取搬运石料。重复接取后核对只有同一轮的一批石料。途中重启后按任务页前往镇口工地。验证由工地管事收货，石料扣除与本轮报酬同步保存。重复交付和重启时按一轮计奖，交付后回采石场可接下一轮。按试算交付两轮共得 200 铜钱、40 潜能和 80 实战经验。[搬运石料](design.md#搬运石料)
- 分别打开村长和中年妇人的对话，核对两项都直接派发。拜访只有接取后的指定谈话才完成。已有布可交付，交前耗掉布会恢复缺一份的提示。补齐后确认交布，重启核对扣除一份布及到账的 75 铜钱、15 潜能、30 经验。再次找她时本任务保持完成。[拜访镇民](design.md#拜访镇民) · [寻物](design.md#寻物)
- 完成一轮拜访和一次寻物，分别核对当次入账，奖励共计 115 铜钱、27 潜能、50 实战经验。以自备布料计，第二轮拜访完成后累计增量为 155 铜钱、39 潜能、70 实战经验，重启后余额一致。
- 测量从村长派发到与目标谈完的路线与补给耗时，按每轮 20 点实战经验与搬运比较单位时间收益。[拜访耗时试算](rewards.md#补给与铜钱)
- 试武交付前后分别找捕快，核对追缉前置条件与第 1 档自动派发。重开对话及读档，核对目标、地点、对手配置和奖励一致。其他交战获胜保持进行中，赢下指定交战后当场完成。核对第 1、5、10 档气血、内力上限。
- 固定抽取值为 0 和 79，核对第 1 档经验与潜能分别为 80、20 和 159、39，第 10 档分别为 800、200 和 1590、397。第 5 档抽取 79 时，获胜即到账 795 经验和 198 潜能，重启或确认普通战利品后累计仍为一份。
- 追缉完成且距该轮接取恰好 300 个游戏时间单位时，向捕快对话核对时间提示。推进至 301 再对话即触发下一轮。第 1、9、10 档完成后分别派第 2、10、2 档。
- 追缉进行中且距接取恰好为 1199 个单位时开战，重启续战，获胜时完成并到账。仍在探索的角色到第 1200 个单位再尝试开战，本轮过期，找捕快自动降档重派。第 5 档降至第 4 档，第 1 档仍为第 1 档。
- 配置一项在交付时每轮发 4 点潜能和 3 点实战经验的重复任务。完成两个不同轮次并各自交付，核对总共得到 8 点潜能与 6 点实战经验，重复提交同一轮交付时按一轮计入。
- 用接取前已有的一份布同时满足两个寻物任务的数量条件。任选其一交付，重启后核对扣除一份布，并按该任务的配置结算一笔报酬。另一项处于进行中并提示还缺一份。另用一件可交付的护腕验证穿戴后数量不足、卸下后可交付。用接取前后的交谈和胜利记录核对事件目标，符合指定任务阶段的操作计入当前轮次。
- 在进行中的任务要求赢得某个正式挑战时完成首胜。按样例在胜利时发 5 点实战经验，交付任务再发 3 点，累计为 8 点。下一轮重复任务时核对只有本轮配置的交付奖励，同一挑战的首胜经验累计仍为 5 点。

### 探索与剧情

- 在药材纠纷中选择帮游方郎中，核对对话直接派发查杀。确认玩家击杀指定目标后任务完成，40 潜能、80 实战经验和疗伤散 ×2 同时到账。重启核对死亡记录和奖品各一份。另走其他剧情分支，核对查杀触发条件。[查杀指定人物](design.md#查杀指定人物)

### 任务存档

- 模拟家务派发、完成发奖及寻物交付时写入失败。排除写入故障后重试，核对沿用原派发结果，目标、物品扣除和奖励各提交一次。旧档中已做完未领奖的家务在读档时结算，随下一次成功保存写入，重复读档的余额一致。
