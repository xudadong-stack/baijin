# 玩法范围

## 产品目标

做一款可在手机上分段游玩的横屏单机武侠 RPG。玩家在离线状态下建角，从主角家出门进入小镇，通过任务获得潜能并学习武学。切磋用于检验成长，获胜后有机会获得战利品。

成长循环为 **建角 → 探索和委托 → 获得潜能 → 拜师习武 → 文字回合战 → 结算并继续成长**。用原创的地图、人物、门派、事件和主线呈现这个循环。

## 游戏内进度

以下内容属于同一个完整版本。角色在同一份存档里按任务、武学和剧情条件推进。完整版本验收通过后，再考虑部署上线。[验收规则](acceptance.md)

| 角色进度 | 可开展的玩法 |
| --- | --- |
| 开局 | 从小镇的老婆婆、师父和陪练开始家务、校场口信和切磋。可拜青衡门或渡川门，习得基本拳脚和本门入门拳法，也能购粮、饮水、查看任务和战利品 |
| 中期成长 | 师门接引授试武棍法并开放穿戴和买卖，校场试武交付后可继续本门的兵器、内功、轻功及进阶招式。另有师门演练、搬运石料、拜访镇民、寻物和捕快追缉。[门派路线](modules/martial-arts.md#两条门派路线) |
| 剧情探索与终局 | 多区域探索、原创主线、郎中查杀等剧情支线、换物与隐藏秘笈。两条门派路线集齐六派信物、验印并作出主线选择后进入同一场终局挑战。[终局挑战](modules/world.md#终局挑战) |

地图、门派和主线章节的具体内容随设计定稿，统一纳入完整版本验收。[任务设计](modules/quests/design.md)

## 开局规则

| 系统 | 玩家动作与结果 |
| --- | --- |
| 四维建角 | 选择性别并分配膂力、敏捷、悟性和根骨，界面显示分配结果及其影响。确认后生成隐藏的幸运并确定相貌，保存角色并进入起点。人物面板显示相貌描述。[幸运](modules/character.md#幸运) · [相貌](modules/character.md#相貌) |
| 地图与 NPC | 用方向键在小镇探索。老婆婆给家务差事，师父给联络委托并提供拜师习武，陪练提供切磋。每名 NPC 有自己的善恶值与对当前角色的好感度 |
| 潜能与任务 | 建角后可向师父接取校场口信，与老婆婆的家务差事并行。校场口信在接取后向陪练确认消息，再回师父处交付并领一次潜能奖励 |
| 任务页 | 从 NPC 对话接取和交付任务。任务页显示已接任务的当前进度、下一步目标、待满足条件和交付对象 |
| 家务差事 | 实战经验低于 5000 时，与老婆婆对话会随机派一件家务。扫地、打水或劈柴完成时获得 50 铜钱、10 潜能和 20 实战经验。达到 5000 后停止派发，已有家务仍可完成并发奖 |
| 开局潜能分配 | 校场口信的潜能奖励足够任意合法建角习得两项武学。两项武学均已习得后，可在潜能和学习条件满足时继续提升等级 |
| 门派与武学 | 习得基本拳脚即提高徒手普攻威力，入门拳法习得后自动运用。请教成功时同步扣除潜能并习得或提升武学，条件不足时提示缺项。成长后可学更多基本功并按装备或用途选择运用的武学。[武学成长](modules/martial-arts.md) |
| 回合战 | 建角后可直接找陪练切磋，尚未习得武学时也可以普通攻击出手。出手由一次判定得出命中或闪避，双方敏捷与招式命中修正参与计算。双方共用普攻公式，被命中后自动判定招架。招架成功则挡下攻击，其余命中先浮动威力，再由防护按点抵扣。普通伤害大于 0 时才判定暴击。日志显示出手、命中或闪避、招架、暴击、伤害及胜负。成长后武学、装备和状态参与修正，达到组合门槛可用进攻和防御招式。[战斗规则](modules/combat.md#战斗规则) |
| 获胜与确认 | 获胜时按陪练的固定掉落表确定本场战利品，并保存胜负与掉落结果。新场次可再次取得同种物品。玩家确认结果后，战利品入背包并继续探索，每场只领取一次。空掉落也显示结果页并可确认继续 |
| 战败处置 | 将对手的善恶值与其对角色的当前好感度相加。总和大于或等于 0 时被放过，留在交战地点并直接回到探索界面。总和小于 0 时被杀，可从死亡结果页读取战前存档 |
| 背包 | 同款物品和装备按数量显示，可食用背包中的口粮。交付师门接引后开放装备穿戴和备战买卖。校场试武交付及六派信物进度会增加货单。[商贩与货单](modules/items.md#交易) |
| 继续游戏 | 从最近一次成功保存的状态继续，包括位置、委托与差事进度、潜能、实战经验、武学、铜钱、背包、NPC 好感度、游戏时间、饥饿度和口渴度。切磋进行中时恢复最近保存的回合和日志。获胜待确认或战败被杀时回到对应的结果页，再由玩家确认胜利结果或读取战前存档 |

初始点数、属性范围、学习消耗、战斗系数和奖励数值由试玩配置定义，计算规则由 `game-core` 实现。首次实现随内容数据给出可验证样例，再根据完整开局的实际耗时和成长反馈调整。

## 吃喝与自然恢复

- 新角色的饥饿度和口渴度均为零。探索时每次成功移动推进一个游戏时间单位。练功、打坐和钓鱼按各自规则推进时间。两项按各自的配置间隔增加，达到各自上限后封顶。
- 战斗按独立的回合计数，饥饿度、口渴度和自然恢复沿用游戏时间的推进规则。[战斗时间](modules/combat.md#战斗规则)
- 老婆婆在自家院门旁售卖口粮。通过对话查看售价并用铜钱购买，购买成功时扣除售价并将一份口粮放进背包。试玩配置规定初始铜钱和口粮售价，售价须大于零，初始铜钱至少够买一份。[老婆婆](modules/npcs/town-street.md#老婆婆)
- 饥饿度大于零时，从背包食用口粮会消耗一份并降低饥饿度。角色必须到井边，才能通过水井交互喝水。口渴度大于零时，喝水会降低口渴度。两项最低降至零。
- 每次游戏时间推进时，先结算饥饿度和口渴度的增长，再判断自然恢复。两项都低于各自上限时，气血可逐步恢复至有效气血上限。角色无伤时，有效上限等于气血上限。内力自然恢复沿用同一吃喝条件。
- 两项的上限与增长间隔、每次吃喝的补充量、自然恢复间隔和恢复量由试玩配置定义。

各系统的试算规则与边界场景见 [玩法模块索引](gameplay-rules.md)。完整版本的通过条件见 [验收规则](acceptance.md)，横屏界面与状态归属见 [模块边界与架构](architecture.md)。
