# 完成前验证

对照用户要求和 [验收规则](../../../docs/acceptance.md) 列出本次要证明的结果，从 [README.md](../../../README.md) 及现有工程配置定位对应命令或实测入口。检查输出和结束状态，确认覆盖实际变化。

| 交付主张 | 核对依据 |
| --- | --- |
| 文档或技能可用 | 文件实际存在，交叉引用可到达，技能元数据和目录名一致，所述命令对应实际工程阶段 |
| 玩法规则通过 | 相关 JVM 测试通过。缺陷回归有修复前的失败复现与修复后的正确结果 |
| Android 包可构建或安装 | 调试包实际构建成功。报告安装成功时核对设备安装结果 |
| 横屏、触控或生命周期正常 | 在 Android 设备或适用模拟器上走过相应流程。设备类型与覆盖范围写入结果 |
| 存档可恢复或迁移 | 按受影响场景取已保存或旧版本样例，验证重启、失败恢复及关键进度 |

先跑与改动直接相关的检查，共用模块或内容引用变化时补查实际消费者。输入发生变化时重跑受影响的检查，相关输入相同且证据已覆盖本次改动时可复用结果。

完成说明列出本次改动、实际检查结果和待验证项。当前文档阶段以 Markdown、相对路径、配置结构和阶段表述的检查为证据。工程和真机验收在对应入口可用时各自记录。
